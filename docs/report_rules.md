# HER report rules

Apply these preferences when creating or editing a report. Follow the user's latest request for the specific report. Use Employee Salary Withdrawals as the working example for row highlighting, clickable amounts, explanations and row actions.

## Start with the question

- Check what Crane Operations already offers. A summary should answer its question at a glance. Keep transaction history, aging buckets and secondary columns in the statement or detail view when they clutter the summary.
- Show the filters that change the answer. For a multi-entity report, leave the entity filter optional so a blank selection shows all permitted records. Put less-used filters under More Filters. A report asking “what is the balance now?” should open on today's balance.
- Put new user-facing operations reports in the relevant Crane Operations workspace section. Check existing coverage before adding a duplicate shortcut or removing a report from the workspace.

## Make each row easy to follow

- Show one clickable human-readable name for a crane, employee or partner. Use the document ID as the link target. Give the full row a blue hover highlight so the reader can follow it across a wide table.
- Make figures that invite investigation clickable. Clicking Income should open the income behind that exact amount. Clicking Expenses on the same row should open its expense breakdown. Preserve the company, period, row and metric, and link the supporting documents.
- Use plain business terms. Give unfamiliar terms and calculated differences a short hover explanation or an info icon that explains what the figure means.
- Size columns for their actual labels, amounts and buttons. Check Arabic and English for clipped button text and overlapping chart labels. When a report includes a row action, open the correct form with the row's entity and relevant HER defaults filled in.

## Use color and charts consistently

- Use green for income or inflows and light red for expenses or outflows. Carry a metric's color from its table column to its chart and summary card. Give different measures distinguishable colors and keep their text labels visible.
- Choose a chart that answers the report's question. For example, compare payment modes with bars, show balance over time with dates on the horizontal axis and balance on the vertical axis, or use stacked bars and a companion donut when both the breakdown and overall shares matter.

## Make totals trustworthy

- End tables of additive amounts with a clearly labeled total row. Count each source once, including when detail rows appear beneath subtotals. Use the appropriate closing value for running balances and calculate ratios from their components.
- Calculate posted financial figures from submitted sources and reconcile them to the relevant accounting records. If draft information is useful, make it opt-in with Show Drafts and display it separately from posted totals.
- Verify a representative filtered result end to end. The summary, chart, table total and clicked detail should agree for the same measure and scope. Open a name link and check that the detail rows explain the selected amount.
