# تقرير توزيع أرباح الرافعات

افتح **Crane Operations → Crane Profit Distribution**، أو ابحث عن **توزيع أرباح الرافعات**. يوجد أيضًا زر **Profit Distribution Details** في عمليات الونش وقائمة View بالتسوية.

التقرير يقرأ التسويات المحفوظة ودفتر الدفع الأصلي؛ لا يعيد الحساب أو ينشئ قيودًا. يعرض نصيب الشركة من التشغيل ومن توزيع المتبقي مستقلين، واستحقاقات الشركاء وسدادها. متاح لأدوار Accounts Manager وSystem Manager مع صلاحيات قراءة المستندات المرتبطة.

## طرق العرض

| العرض | ماذا يوضح؟ |
| --- | --- |
| ملخص التسويات — Settlement Summary | صف لكل تسوية: الإيراد، نسبة وحصة التشغيل، المتبقي بعد التشغيل، المصروفات، الخسارة السابقة، وعاء التوزيع، نصيب الشركة من التشغيل والمتبقي والإجمالي، استحقاق الشركاء، مدفوعاتهم والتسويات الأخرى والمتبقي لهم. |
| ملخص الشركة والشركاء — Participant Summary | يجمع كل طرف عبر التسويات المختارة: حصة التشغيل، نصيب المتبقي، أثر المصروفات، إجمالي النصيب، الاستحقاق المرحل، المدفوعات والمتبقي. لا يجمع نسبًا قد تختلف بين الاتفاقات. |
| تفاصيل التوزيع — Distribution Details | صف لكل طرف في كل تسوية، مع نسب الملكية وتوزيع المتبقي المحفوظة، وحصة التشغيل، ونصيب المتبقي قبل المصروفات وبعدها، وأثر المصروفات، والمدفوعات والأرصدة. |
| مصادر الإيرادات والمصروفات — Source Details | مستندات المصدر وروابطها وتواريخها، والمبالغ المخصصة للتسوية وأساس التخصيص وفترة الخدمة وحساب الإيراد. Expense Entry يتفصل حسب أنواع مصروفاته. مبلغ المصدر الكامل للمرجعية فقط ولا يُجمع مرة أخرى. |
| حركة الاستحقاق والسداد — Entitlement Movements | لكل شريك وتسوية: قيد زيادة الاستحقاق، سندات السداد أو التسويات المخفضة له، والرصيد المتحرك. رصيد الحركة خاص بهذا الشريك وهذه التسوية، وليس رصيد خزينة أو كل حساب الشريك. |

البطاقات العليا تجمع **التسويات المعتمدة المختارة مرة واحدة**، حتى لو ظهرت عدة صفوف للشركاء أو المصروفات. تقديرات الشركاء في المسودات تظهر في بطاقة منفصلة. الإجماليات بالجدول منفصلة للمعتمد والمسودة، ولا تجمع النسب أو الأرصدة المتحركة.

يعرض الرسم المبالغ حسب الرافعة أو المشارك أو نوع المصدر وفق العرض المختار. عند اختيار الكل تظهر المسودات منفصلة عن التسويات المعتمدة. يعرض الرسم أكبر عشر فئات عند كثرة النتائج ويبقى الجدول كاملاً.

## الفلاتر

افتح **مرشحات إضافية** للوصول إلى حالة التسوية وحالة الاستحقاق وروابط المستندات.

- **الشركة:** إلزامية، وتحدد العملة. لا يوجد جمع لعملات شركات مختلفة.
- **الرصيد حتى تاريخ — Balance As Of:** تاريخ حساب المدفوعات والأرصدة من دفتر الدفع. لا تظهر تسويات أو قيود استحقاق مرحلة بعده.
- **أساس الفترة — Date Basis:** فترة العمل، أو تاريخ ترحيل التسوية.
- **من / إلى:** في وضع فترة العمل، يختار التقرير التسويات التي تتداخل فترتها مع الاختيار. يعرض التسوية كاملة ولا يوزعها جزئيًا على أيام الفلتر. في وضع تاريخ الترحيل يختار تاريخ ترحيل التسوية.
- **الونش، أمر الإيجار، سجل العمل، التسوية، فاتورة البيع، العميل:** لتضييق المستندات المطلوبة. سجل العمل يشير إلى رابط التسوية المباشر؛ التسويات التاريخية المستقلة تظل مرتبطة بفترتها ومصادرها.
- **الشريك:** يختار التسويات التي تشمل هذا الشريك. في عرض التوزيع وملخص الأطراف والحركة تظهر صفوف هذا الشريك فقط، مع بطاقات إضافية لاستحقاقه والمسدد والمتبقي له. بطاقات إيراد ومصروفات ونصيب الشركة تظل تعرض سياق التسويات الكاملة، وليست إيرادًا منسوبًا كله للشريك المختار.
- **حالة التسوية:** المعتمد افتراضيًا، أو المسودات، أو الكل. الملغى مستبعد.
- **حالة الاستحقاق:** غير مدفوع، مدفوع جزئيًا، مدفوع، بلا استحقاق، مسودة أو انتظار الفاتورة. يختار التسويات المطابقة، وصفوف الشركاء المطابقة في عروض الأطراف والحركة.
- **الطرف:** الكل، شركتنا، أو الشركاء الخارجيون؛ متاح في عروض الأطراف والحركة. حركات استحقاق الشركاء لا تنشأ لنصيب الشركة المحتفظ به.

مثال: اختر الشركة **cranes company**، الونش **CR-00074**، وفترة العمل من **2026-11-01** إلى **2026-11-13**، والرصيد حتى **2026-11-13**.

## مطابقة مثال CR-00074 / CPS-00023

| البيان | المبلغ بالجنيه |
| --- | ---: |
| الإيراد | 48,000 |
| تشغيل الشركة 10% | 4,800 |
| المتبقي بعد التشغيل | 43,200 |
| المصروفات | 50 |
| وعاء توزيع المتبقي | 43,150 |
| نصيب الشركة من المتبقي 40% | 17,260 |
| إجمالي نصيب الشركة | **22,060** |
| استحقاق كل شريك 20% | **8,630** |
| إجمالي استحقاق الشركاء | **25,890** |

أثر المصروفات: **20 على نصيب الشركة و10 على نصيب كل شريك**. هذا شرح لكيفية انخفاض نصيب المتبقي، وليس قيد مصروف جديدًا. يُحسب الفرق بين النصيب المقرب قبل التكاليف وبعدها حتى يطابق مبالغ التسوية إلى آخر قرش؛ وفي المسودات العاجزة قد توجد تكاليف تتجاوز وعاء التوزيع المتاح. نسب الملكية ونسب توزيع المتبقي مستقلة؛ أثر المصروف يتبع نسبة توزيع المتبقي، حتى لو اختلفت عن الملكية.

## حدود القراءة المهمة

- **إجمالي نصيب الشركة ليس نقدية متاحة للسحب.** هو نتيجة توزيع محفوظة؛ تحصيل العميل وتوافر البنك والخزينة مستقلان.
- **مدفوعات الشركاء** تأتي من حركات Payment Entry المرتبطة بقيد الاستحقاق. الحركات الأخرى تُعرض كتسويات أخرى؛ المتبقي مطابق لدفتر الدفع الأصلي. سندات المسودة لا تعتبر مدفوعة. الملغى وحركات دفتر الدفع المفصولة مستبعدة؛ التقرير لا يعيد بناء حالة تاريخية قبل إلغاء لاحق.
- أرقام المسودات هي آخر حساب محفوظ؛ إعادة الحساب تتم من التسوية بعد تغيير المصادر. لا يرحل التقرير المسودات أو يعيد حسابها.
- الاتفاق والنسب والمبالغ من لقطة التسوية، وليست نسب الونش الحالية. التعديلات اللاحقة على الاتفاق لا تغير التسويات السابقة.
- إذا كانت بعض مصادر لقطة التسوية بتاريخ ترحيل لاحق لتاريخ الرصيد، يظهر تنبيه. عرض اللقطة لا يعني إعادة بناء تقدير التكاليف كما كان في يوم سابق.
- إذا تعذر الوصول إلى مستند مصدر أو قيد أو سند دفع، يفشل التقرير بصلاحيات واضحة بدل عرض ربح أو رصيد ناقص.
- يشمل التقرير العمل المرتبط بتسوية محفوظة. ليس بديلًا لتقرير Rental Profitability، ولا يعرض أعمالًا لم تُنشأ لها تسوية أو مصروفات غير داخلة في مصادرها.

استخدم تصدير Excel/CSV والطباعة من أدوات التقرير الأصلية. لا توجد قيود محاسبية أو مستحقات جديدة ناتجة عن فتح التقرير أو تصديره.


## لوحة المستحقات والشراكة

افتح **عمليات الرافعات ← لوحة المستحقات والشراكة**، أو المسار `/app/crane-distribution-dashboard`. يمكنك فتحها أيضًا من زر اللوحة داخل تقرير توزيع الأرباح.

- بطاقات ملونة للإيرادات والمصروفات وحصص الشركة ومستحقات الشركاء والمدفوع والمتبقي، مع تقديرات المسودات منفصلة.
- فلاتر عربية للشركة والفترة وأساسها وتاريخ الرصيد والونش والشريك والحالات، وفلاتر إضافية للمستندات والأطراف. تتحدث النتائج تلقائيًا؛ زر إعادة الضبط يعيد الشهر الحالي والشركة الافتراضية.
- اضغط حالة الاستحقاق لتصفيتها. العدد هو عدد استحقاقات الشركاء عبر التسويات، وليس عدد الشركاء الفريدين.
- خمس طرق عرض بنفس تفاصيل التقرير، وبحث داخل صفوف التفاصيل، وصفحات من 25 صفًا وروابط للمستندات الأصلية. البحث داخل الجدول لا يغير البطاقات أو الحالات.
- زر «فتح التقرير / تصدير» ينقل فلاتر اللوحة إلى التقرير الأصلي للاستفادة من التصدير والطباعة.
- بطاقات الإيراد والتكاليف والشركة تحتفظ بالسياق الكامل للتسويات المختارة. فلتر الطرف يخص صفوف التفاصيل؛ عند اختيار شريك أو حالة تظهر بطاقات إضافية للمستحقات المطابقة.
- تدعم الهاتف واتجاه الكتابة العربي، وحركات خفيفة تتوقف تلقائيًا عند تفضيل تقليل الحركة في الجهاز.
